# VirtRigaud Adopters

This is a list of organizations that use VirtRigaud in production, in
pre-production, or in their own products and services. It helps new users see
where the project is already in use, and helps the maintainers understand how
it is used.

If you use VirtRigaud, please add your organization. Being listed is optional
and is not an endorsement by the project.

## Adding your organization

1. Fork this repository.
2. Add a row to the table below. Keep the table in alphabetical order by
   organization name.
3. Open a pull request titled `docs(adopters): add <organization>`, following
   [CONTRIBUTING.md](CONTRIBUTING.md).

Only add an organization you are authorized to represent. Do not include
internal hostnames, environment details, or other confidential information.

The columns are:

- **Organization:** the organization's name, linked to its website.
- **Contact:** a GitHub handle the maintainers can reach about this entry.
- **Since:** the year and month you started using VirtRigaud (`YYYY-MM`).
- **Stage:** `Production`, `Pre-production`, `Evaluation`, or `Product`
  (VirtRigaud is part of something you ship to others).
- **Description of use:** one or two sentences, for example which hypervisors
  you manage and what you use VirtRigaud for.
